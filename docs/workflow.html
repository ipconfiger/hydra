Key policies

The guarantees and trade-offs encoded across the pipeline.

Auth

Cache-first, 5-min TTL. Denials cached with a short TTL. DELETE /api/v1/auth/cache forces re-auth on next request.

Routing

model ∩ TenantModel-gate ∩ online providers ∩ tenant-allowed. Nginx SWRR weighted round-robin orders the candidates.

Failover

Connect failure always retries the next candidate. Mid-proxy defaults to no retry (retry_after_connect=false) — prevents duplicate billing.

Circuit breaker

N consecutive failures → provider enters dead-set and is skipped. A background probe revives it once it heals.

Rate limit

In-memory sliding window — count pre-flight + tokens post-flight, across m / h / d windows.

Zero-copy

Body flows untouched. model / usage found by memchr scan only; first chunk replayed via enable_retry_buffering.

Usage

Tokens parsed from the SSE tail (OpenAI / Anthropic multi-schema) → SQLite (or ClickHouse) for analytics and billing.

TLS

SNI-based per-tenant certificate (BoringSSL callback) with hot-reload — no restart needed to rotate certs.
